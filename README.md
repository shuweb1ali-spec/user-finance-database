# user-finance-database
A beginner level Python application that uses SQLite3 to create a database for tracking finances. The user will be able to add to the database and check the existing entries along with it.

# Main Features
- User Transactions: Add an expense with a unique category, specifics, amount, and description. The specifics indicate the exact type (E.g. Food = Pizza, Burger, Chips, etc.)
- Showing Transactions: Show the entire database with all the rows and columns displayed to you
- Prevents SQL Injection: Parameterized queries can help enhance security

# Program
- Python
- SQLite3

# How To Run
- Download file
- Open terminal and use bash python Finance.py
